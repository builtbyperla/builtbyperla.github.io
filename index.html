Percolate

A text editor with an annotation-based interaction model for working with AI coding assistants.

Try the demo ↗

Context

The user can select code, attach notes and comments to it, manage these annotations in a unified interface, and attach them to messages it sends to the AI agent. This also extended to diff views and even the agent's markdown replies.

Status

Backend in development.

Integration and interaction design

  • Annotation state stays synchronized across code, diff, and agent-response views
  • Evidence can be annotated, included, excluded, or automatically consumed after sending
  • Separate in-place read and write modes to avoid visual clutter with a quick-annotate functionality to bridge them.

Tech Stack

Built with SolidJS, TypeScript, Vercel AI SDK, CodeMirror, and Electron.

Ambient Multimodal Storyboard Agent

An ambient meeting agent designed for creative storyboarding.

Context

The agent listens to the active discussion and proactively generates images and updates the board. Speech-to-text transcripts are interpreted during pauses in speech.

Tech Stack

A fully async Python backend (utilizing FastAPI) and a React/TypeScript frontend communicate over WebSockets.

Speech-to-text
ElevenLabs Scribe v2 Realtime API
Agent inference
Anthropic’s Claude models
Image generation
Black Forest Labs’ flux-schnell-9b, running on Replicate
Memory
OpenAI’s text-embedding-3-small for embeddings and GPT for long-term memory summarization

Motivation

A case study in agentic AI applications, focused on four challenges:

  1. Always-on speech-to-text is the primary input mode and the agent must be able to respond and recover accordingly despite external latency factors
  2. The agent operates as an ambient collaborator in creative workflows and makes changes proactively despite not being provided precise instructions or data
  3. The agent interacts directly with complex UI objects on behalf of the user while remaining fully interactive for the end user
  4. Token counts and context must be managed to avoid skyrocketing monetary + performance costs over long user sessions
