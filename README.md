# Demos

A place to host demos made by Perla.

## Available

- [Text Editor](demos/texteditor/index.html) — Text editor with an annotation-based interaction model for working with AI coding assistants.

----

## Adding a demo

1. Drop the static build into `demos/<name>/` with its own `index.html`.
2. Add a link here and a matching `<li>` in [index.html](index.html).

`.nojekyll` is present so GitHub Pages serves files and directories verbatim.
